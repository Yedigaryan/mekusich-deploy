# Gallery Images

Please add your gallery images here. The gallery component expects images with the following names (currently custom SVG placeholder illustrations):
- 1.svg
- 2.svg
- 3.svg

Replace them with real photos (e.g. 1.jpg, 2.jpg, 3.jpg) and update the `gallery` array in `app/lib/content.ts` to match your image filenames.

Recommended format: JPG or WEBP, optimized for web (800x600px or similar aspect ratio).
